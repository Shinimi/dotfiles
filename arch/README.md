# arch/: yu's vanilla Arch setup

**The install guide is the repo's front page: [README.md](../README.md).** Made by Claude.

| File | What |
|---|---|
| `setup.sh` | Run once after the install: packages, AUR apps, login screen, dark GTK/Qt, Games drive, configs, wallpapers, Claude chat restore; runs `tune.sh` last |
| `tune.sh` | Fast like CachyOS · safe like Debian · secure like Fedora (re-runnable on its own) |
| `hypr/hyprland.lua` | Minimal Hyprland: your screens, Turkish keyboard, flat mouse, monochrome glass, window rules, keys |
| `noctalia/config.toml` | Noctalia in monochrome, clean floating bar, none on the side screen |
| `zshrc` | zsh with your Frieren fetch, Powerlevel10k, suggestions + highlighting |
| `CONTEXT.md` | Where things stand, preferences, what's left: for continuing with Claude |
